## ۲) خلاصهٔ هر تغییر

### ۲-۱) یکسان‌سازی برند عمومی به «خرازی پرنسا» (بند أ)

- `general_settings.site_name` → «خرازی پرنسا» و `general_settings.logo` → لوگوی جدید.
- تمام متن‌های عمومی «دریکانا / DRIKANA / طلا / جواهر / شناسنامه طلا / گواهی اصالت / مالکیت / سرقت / تعمیر جواهرات» از دید کاربر حذف شد.
- **هیچ نام کلاس، جدول یا شناسهٔ فنی تغییر نکرد.** تنها باقیماندهٔ رشتهٔ `drikana` در خروجی HTML، نام فایل `drikana-luxury.css` است که عمداً حفظ شد.
- لوگو، هدر، فوتر، منوی موبایل و مگامنو با آیکون‌های مناسب خرازی (قیچی، سوزن، نخ، روبان) بازنویسی شدند.
- **هیچ آماری اختراع نشد.** ادعاهای ساختگی («+۱۰ سال»، «+۵۰K مشتری»، «۱۰۰٪ گارانتی اصالت»، «بلوکزنجیره»، «اسکورت مسلح») حذف شدند.

### ۲-۲) غیرفعال‌سازی کنترل‌شدهٔ ماژول جواهرات (بند ب)

- هر ۵۷ مسیر از `web.php` به `routes/jewelry.php` منتقل شد و تنها در صورت `KHARAZI_ENABLE_JEWELRY=true` بارگذاری می‌شود.
- **هیچ فایلی، جدولی یا مجوزی حذف نشد.** ۴ جدول ماژول و ۳۰ مجوز `jewelry.*` دست‌نخورده باقی مانده‌اند.
- لینک‌های `route('jewelry.*')` از همهٔ ویوهای عمومی حذف شد → خطر `RouteNotFoundException` صفر است.
- `products.mens` و `products.womens`: به `Route::permanentRedirect` به `/categories` تبدیل شدند. **نام مسیر اصلی حفظ شد** تا ارجاعی نشکند؛ هر دو نشانی اکنون `301 → 200` می‌دهند.

### ۲-۳) لایهٔ مستقل قالب روشن (بند ج)

- فایل جدید `kharazi-theme.css` **آخرین** CSS بارگذاری‌شده است؛ حذف تنها `<link>` آن، کل قالب را به حالت قبل برمی‌گرداند.
- پالت: فیروزه‌ای `#0f7b7b` (اصلی)، مرجانی `#ff6b52` (تخفیف/برچسب)، پس‌زمینهٔ `#f7fafb`، کارت سفید.
- متغیرهای `:root` (شامل `--d-gold*`، `--d-navy-*`، `--grad-*`، `--shadow-*`) بازنویسی شدند.
- **`utilities.css` و `drikana-luxury.css` اصلاً دست نخوردند.**

### ۲-۴) رفع اشکال‌ها (بند د)

| اشکال | راه‌حل انتخابی | دلیل |

### ۲-۵) قابلیت‌های درخواستی افزودهٔ شما

- **درون‌ریزی گروهی محصولات:** مسیرهای آن موجود و سالم است (آزمون زیر). اشکال ناسازگاری ستون‌ها (B-1) مربوط به مرحله ۶ است و در این مرحله دست نخورد.
- **فایل پایگاه داده:** هر دو فایل SQL از پایگاه دادهٔ زنده بازتولید شدند.

2. توکن گیت‌هاب را باطل کنید و نشانی remote را بدون توکن تنظیم کنید.

### 🟡 ۴-۷) `vendor/` هنوز رهگیری می‌شود

## ۵) فرمان‌های لازم برای استقرار در محیط مقصد

### ۵-۱) آماده‌سازی کد
```bash
git clone <repository-url> kharazi
cd kharazi
git checkout feature/kharazi-rebrand
```

### ۵-۲) فایل محیطی
```bash
cp .env.example .env
php artisan key:generate          # کلید جدید می‌سازد (اجباری)
nano .env                         # مقادیر واقعی سرور را وارد کنید
```
مقادیری که **باید** در `.env` پر شوند: `DB_*` , `APP_URL` , و در صورت نیاز `MAIL_*` و کلیدهای پیامک/پرداخت.

### ۵-۳) نصب وابستگی‌ها
```bash
composer install --no-dev --optimize-autoloader
```

### ۵-۴) پایگاه داده
**گزینهٔ الف — بازگرداندن کامل (پایگاه دادهٔ خالی):**
```bash
mysql -u root -p -e "CREATE DATABASE peransa-db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -p --default-character-set=utf8mb4 peransa-db < database/peransa-db.sql
```

**گزینهٔ ب — به‌روزرسانی تکرارپذیر (پایگاه دادهٔ موجود):**
```bash
mysql -u root -p --default-character-set=utf8mb4 peransa-db < database/peransa-db-amn.sql
```
> این فایل با `CREATE TABLE IF NOT EXISTS` و `INSERT IGNORE` ساخته شده؛ جدول‌ها و سطرهای موجود را دست‌نخورده می‌گذارد. آزمون بارگذاری دوبارهٔ آن با ۰ خطا قبول شد.

### ۵-۵) مجوزها و پاک‌سازی کش
```bash
chmod -R 775 storage bootstrap/cache
php artisan config:clear
php artisan route:clear
php artisan view:clear
php artisan cache:clear
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

### ۵-۶) پیوند نمادین فایل‌های بارگذاری‌شده
```bash
php artisan storage:link
```

### ۵-۷) ماژول جواهرات
به‌صورت پیش‌فرض **خاموش** است و هیچ کاری لازم نیست.
برای روشن‌کردن موقت آن: `KHARAZI_ENABLE_JEWELRY=true` در `.env` و سپس `php artisan config:clear`.

### ۵-۸) بازگشت به حالت قبل (Rollback)
```bash
# ۱) بازگرداندن کد به وضعیت پیش از برندسازی
git checkout main

# ۲) حذف لایهٔ قالب روشن (اگر بخواهید فقط ظاهر را برگردانید)

# ۳) بازگرداندن پایگاه داده
mysql -u root -p -e "DROP DATABASE peransa-db; CREATE DATABASE peransa-db CHARACTER SET utf8mb4;"
mysql -u root -p --default-character-set=utf8mb4 peransa-db \
  < /home/user/backups/peransa-db-before-rebrand-20261016-151117.sql
```

**پشتیبان‌های موجود:**
- پایگاه داده پیش از برندسازی: `/home/user/backups/peransa-db-before-rebrand-20261016-151117.sql` (۷۲ جدول)
